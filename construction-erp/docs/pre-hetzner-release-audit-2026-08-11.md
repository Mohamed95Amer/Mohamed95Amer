### Security

The audit found a release blocker: core Property models had ACLs but lacked a
complete company-level row boundary. The fix adds global allowed-company rules
to all 28 Property business models and a permanent post-install regression.

The regression proves that a Company A user cannot discover Company B's:

- developments or units;
- leases;
- service-charge budgets;
- listings.

The test also asserts every required rule exists, is global, and uses
`company_ids`. Result: 5 focused security tests and the full clean suite pass.
