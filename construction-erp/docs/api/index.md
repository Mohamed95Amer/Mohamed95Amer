# Majal API

Integration documentation for **Majal**, a Construction & Facilities Management ERP
built on **Odoo 18 Community**.

Majal exposes two distinct surfaces:

1. **Odoo's standard external API** — XML-RPC and JSON-RPC. This is the whole ORM:
   every Majal model, field and public method. It is what you will use for 95% of
   integrations.
2. **Majal's own HTTP controllers** — a small, deliberate set of routes for asset
   tag scanning, the offline field app, the customer/subcontractor portal, CSV
   export and the WhatsApp webhook.

There is no separate REST API, no GraphQL endpoint, and no `/api/v1/...` namespace.
If a route is not listed in Custom endpoints, it does not exist.

## Conventions used in these docs

Placeholders are always written in this form and must be replaced:

- `https://your-host` — the Majal base URL
- `YOUR_DATABASE` — the database name (Majal ships single-database; commonly `erp`)
- `YOUR_LOGIN` — the user login (an e-mail address)
- `YOUR_API_KEY` — a developer API key generated by that user

No sample in these docs contains a real credential, hostname or token.
