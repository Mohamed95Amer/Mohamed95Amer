# Majal Property Integrations

This module adds three credential-free or fail-closed essentials:

1. Development addresses, coordinates and a browser-opened map link. Majal does
   not send a server-side geocoding request and no Maps key is required.
2. Provider-neutral listing channels. A validated, versioned snapshot is created
   before any export. API queueing is refused until a separate approved adapter
   is installed, configured and activated.
3. A company-isolated reminder center for installments, leases, reservations
   and expiring documents. Internal reminders are generated by default. Email is
   off by default and, when enabled, messages enter Odoo's native outgoing queue;
   external delivery never runs inside the Property screen request.

## Safety boundary

- No provider secret value is stored in the database; only an environment
  variable name may be saved in `majal.integration.provider`.
- Endpoints must use HTTPS and cannot contain embedded credentials.
- Provider calls use idempotent background jobs with bounded retries.
- Company rules isolate providers, channels, publications and reminders.
- A portal name in Majal does not mean an API integration exists. Property
  Finder, Bayut and dubizzle require their current commercial API agreement and
  a dedicated allowlisted adapter before activation.
- Email, API channels and providers are disabled until an administrator tests
  the corresponding server configuration.

## Rollback

Disable the provider or reminder policy first. Pending integration jobs can then
be cancelled. The two modules are separate from Property business models, so
they can be upgraded or removed without changing reservations, leases, units,
installments or invoices.
